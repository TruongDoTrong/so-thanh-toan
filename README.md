# Sổ thanh toán công trình — bản xem trên điện thoại / iPad

Trang: https://truongdotrong.github.io/so-thanh-toan/

Mở file zip hồ sơ thanh toán (chương trình "Theo dõi thanh toán công trình" trên máy tính xuất ra) để
xem: thanh toán kỳ này, tổng hợp theo gói thầu / hạng mục, bảng gói thầu, khách trả tiền, nhật ký.
Chỉ xem, không sửa.

File zip được đọc ngay trên máy người xem, **không gửi lên mạng**. Kho này chỉ chứa trang xem —
không có số liệu công trình nào.

`docs/index.html` sinh bằng `xuat_trang_web.py` từ `xem_dien_thoai.html` (nằm ở thư mục code
chương trình). Đừng sửa thẳng file ở đây.
